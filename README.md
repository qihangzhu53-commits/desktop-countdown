# ⏳ 桌面倒计时

一款简洁、可移动、可自定义的 macOS 桌面倒计时应用。

把毕业、元旦、考试和其他重要日子放在桌面上，让每一天都更有目标感。

## ✨ 功能亮点

- 📅 内置“毕业倒计时”和“2027 元旦倒计时”
- ➕ 支持添加任意数量的自定义倒计时
- 🖱️ 倒计时卡片可以自由拖动
- ↗️ 支持等比例放大和缩小
- 🖼️ 可以为每张卡片设置自己的背景图片
- 📌 支持始终置顶、锁定和隐藏
- 💾 自动保存日期、位置、尺寸和个性化设置
- 🍎 同时支持 Apple 芯片和 Intel Mac

## 🖥️ 系统要求

- macOS 13 或更高版本
- 无需安装其他运行环境

## 🚀 使用方法

1. 打开“桌面倒计时.app”。
2. 在管理中心查看已有倒计时。
3. 点击新增按钮，创建自己的倒计时。
4. 拖动卡片调整位置。
5. 拖动卡片右下角调整大小。
6. 双击卡片或拖入图片，更换背景。

如果 macOS 首次阻止打开，请右键 App，然后选择“打开”。

建议把 App 放进“应用程序”文件夹。如果希望开机自动启动，可以前往：

`系统设置 → 通用 → 登录项`

## 🎨 个性化操作

- 双击卡片：选择背景图片
- 拖入 JPG、PNG 或 HEIC 图片：立即更换背景
- 右键卡片：编辑日期、锁定、置顶、隐藏或恢复默认设置
- 菜单栏计时器图标：新增倒计时、找回卡片或重置位置

## 🛠️ 从源码构建

在项目目录中运行：

`./build.sh`

构建完成后，可安装的 App 和压缩包会生成在 `dist` 文件夹中。

## 📁 项目结构

- `Sources/`：倒计时应用的主要代码
- `Tools/`：图标生成和打包工具
- `Info.plist`：macOS 应用配置
- `build.sh`：自动构建脚本
- `README.md`：项目介绍和使用说明
