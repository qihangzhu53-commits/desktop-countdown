# 桌面倒计时

原生 macOS 桌面倒计时 App。点击 App 会打开完整的“倒计时管理中心”，内置“毕业倒计时”和“2027 元旦倒计时”，还可以随时添加任意数量的自定义倒计时卡片。

支持 macOS 13 及以上版本，同时兼容 Apple 芯片和 Intel Mac。

## 构建

在项目目录中运行 `./build.sh`。完成后，可安装的 App 和压缩包会生成在 `dist` 文件夹中。

## 打开

1. 双击“桌面倒计时.app”。
2. 主页面会列出全部倒计时，可以直接新增、编辑、显示或隐藏桌面卡片。
3. 如 macOS 阻止首次打开，请右键 App，选择“打开”。

建议把 App 放进“应用程序”文件夹；如果希望开机自动显示，可在“系统设置 → 通用 → 登录项”中添加它。

## 操作

- 点击 Dock 中的 App 图标：打开或找回倒计时管理中心
- 主页面：新增倒计时、查看剩余时间、显示/隐藏卡片、编辑和删除自定义倒计时
- 拖动卡片：移动位置
- 拖动卡片右下角：等比例放大或缩小（每张卡片会分别记住尺寸）
- 双击卡片：选择背景照片
- 把 JPG / PNG / HEIC 图片拖到卡片：立即更换照片
- 右键卡片：更换/恢复照片、恢复默认大小、修改日期、锁定、置顶、隐藏或退出
- 菜单栏计时器图标：新增倒计时、找回卡片、重置位置、恢复全部默认大小、锁定或退出
- 新增倒计时：填写名称和日期，可选图标与主题；自定义卡片右键可编辑或删除

卡片默认位于桌面层，不会遮挡普通 App 窗口；需要压在其他窗口上方时，可从菜单栏打开“始终置顶”。

默认毕业日期为 2027 年 6 月 30 日，首次打开时可立即修改；元旦日期固定为 2027 年 1 月 1 日。自定义倒计时会自动保存，下次打开仍会保留。
